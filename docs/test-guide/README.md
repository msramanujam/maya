# Test guides

One guide per feature: `FT-<slug>.md`, named after the feature's backlog
slug. Story-keyed guides (`ST-<slug>.md`) exist only until a feature file
is created, then get renamed.

Written for someone with no knowledge of this repo. Exact commands,
URLs, and clicks — not descriptions of behavior. Every section ends with
an unambiguous pass/fail signal.

Written or updated before the PR, in the same session. A bugfix or
behavior change updates the existing guide; it never adds a new one. No
up-to-date guide, no PR. See `docs/specs/001-dev-workflow.md`.
